# Barnabas Anyaora — Developer Portfolio

## About the Project

This is my personal portfolio website, built to showcase my skills, services, and projects as a full-stack web developer.

The website provides information about my background, the services I offer, and ways to contact me.

## Features

- Responsive portfolio website
- Home, About, and Services pages
- Reusable navigation bar and footer components
- Contact link using email
- Social media links
- Dedicated sections showcasing development services

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Project Structure

- `index.html` — Homepage
- `about.html` — About me page
- `services.html` — Services page
- `css/style.css` — Website styling
- `js/main.js` — Main JavaScript functionality
- `js/components/` — Reusable navigation and footer components
- `images/` — Website images and logo

## Running the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using a local development server, such as the Live Server extension.
